# STS2 game API map (v0.107.1, public branch)

Findings about the game's own types, gathered from a local decompile on Mark's Mac and checked twice (a researcher plus a skeptic per topic, then a re-check against the installed v0.107.1, commit 59260271, Steam build 23811903). This file describes names and behaviour only; no game source is copied here. Full per-topic notes with file:line evidence live on the Mac in `~/Projects/sts2-notes/api-v0.107.1/`.

Build against `SlayTheSpire2.app/Contents/Resources/data_sts2_macos_arm64/{sts2.dll,GodotSharp.dll,0Harmony.dll}`, net9.0.

## 0. Ground rules

- Everything game-side runs on the Godot main thread: state reads, node access, `ForceClick`, `RequestEnqueue`. `NRun._Process` pumps `NetService.Update` every frame. HTTP and LLM work stays off-thread and marshals back (our `MainThreadQueue`, drained on `SceneTree.ProcessFrame`). Never `.Result`/`.Wait()` on the main thread.
- Every combat or map input ends in one synced call: `RunManager.Instance.ActionQueueSynchronizer.RequestEnqueue(GameAction)`, always for the local player.
- Rewards, events, rest sites, shops and treasure have their own synchronizers; drive them through the real UI nodes: `btn.ForceClick()` or `holder.EmitSignal(NCardHolder.SignalName.Pressed, holder)`. `ForceClick` runs the release handler but skips IsEnabled/visibility/focus checks, so check `IsEnabled` yourself and click exactly once (most handlers `SetResult` a TaskCompletionSource; a second press throws).
- Never use `CardSelectCmd.UseSelector`/`PushSelector` (they fabricate remote players' choices; singleplayer-only cheat path).
- `MegaCrit.Sts2.Core.AutoSlay.*` ships in sts2.dll but `--autoslay` is dead (`NGame.IsReleaseGame()` is hard-coded true). Use it as a reference for dispatch, waits and screen clicking only; its combat cheats (`CardCmd.AutoPlay`, `PlayerCmd.EndTurn`, PowerCmd 999 Plating/Regen, global selector) and desyncs co-op.

## a. Run state and the local player

- `MegaCrit.Sts2.Core.Runs.RunManager`: `static RunManager Instance`. `RunState? DebugOnlyGetState()` (null on the menu; widely used despite the name). `bool IsInProgress` (true from SetUp onward, before Launch sets NetId), `IsGameOver`, `IsAbandoned`, `IsSingleplayerOrFakeMultiplayer`, `IsCleaningUp`.
  - `INetGameService NetService`: `.Type` (`NetGameType` Singleplayer/Host/Client/Replay), `.NetId`, `.IsGameLoading`. Null before the first run and stale after CleanUp; read only while IsInProgress.
  - Per-run handles, rebuilt every run (re-read after `RunStarted`): `ActionQueueSet`, `ActionExecutor`, `ActionQueueSynchronizer`, `MapSelectionSynchronizer`, `ActChangeSynchronizer`, `PlayerChoiceSynchronizer`, `EventSynchronizer`, `RewardSynchronizer`, `RewardsSetSynchronizer`, `RestSiteSynchronizer`, `OneOffSynchronizer`, `TreasureRoomRelicSynchronizer`, `CombatStateSynchronizer`.
  - Events: `Action<RunState> RunStarted` (raised in Launch after NetId set; NRun doesn't exist yet, Map is NullActMap, CurrentRoom null), `Action RoomEntered`, `RoomExited`, `ActEntered`.
  - Gaps: ActEntered doesn't fire for act 1 of a Neow start or a loaded run (postfix `Hook.AfterActEntered`). RoomEntered doesn't fire when an event combat pops back to its event. No run-ended event: postfix `RunManager.OnEnded(bool isVictory)` (runs twice on victory, latch the first) and `RunManager.CleanUp(bool)` (every exit path).
- `MegaCrit.Sts2.Core.Context.LocalContext` (static): `ulong? NetId` (1 in singleplayer and on the ENet host). `Player? GetMe(IPlayerCollection)` / `GetMe(ICombatState)` / `GetMe(IEnumerable<Player>)` (null before Launch; the IPlayerCollection overload throws if no player matches). `bool IsMe(Player|Creature)`, `IsMine(CardModel|PotionModel|RelicModel|EventModel)`.
- `MegaCrit.Sts2.Core.Runs.RunState` (IRunState, IPlayerCollection): `Players`, `Map` (ActMap), `CurrentRoom` (AbstractRoom; `.RoomType`), `CurrentRoomCount`, `BaseRoom`, `CurrentActIndex`, `Act` (ActModel), `ActFloor`, `TotalFloor`, `AscensionLevel`, `GameMode`, `Rng` (RunRngSet: `.StringSeed`, `uint .Seed`), `Odds`, `CurrentMapCoord`, `CurrentMapPoint`, `VisitedMapCoords`, `MapPointHistory`.
- `MegaCrit.Sts2.Core.Entities.Players.Player`: `NetId`, `Character`, `Creature` (CurrentHp, MaxHp, Block, Powers), `Gold`, `Deck` (`.Cards`), `Relics`, `PotionSlots` (null entry = empty slot), `MaxPotionCount`, `HasOpenPotionSlots`, `GetPotionAtSlotIndex(int)`, `MaxEnergy` (base), `CanRemovePotions`, `PlayerCombatState`, `RunState`.
- Singleplayer/host/client: `RunManager.Instance.NetService.Type`, only while IsInProgress. Don't test `RunLobby != null` (never nulled). `RunLobby.ConnectedPlayerIds` lists peers.

## b. Combat state

Path: `me = LocalContext.GetMe(rs)`; `ICombatState cs = me.Creature.CombatState` (or `CombatManager.Instance.DebugOnlyGetState()`); `PlayerCombatState pcs = me.PlayerCombatState`. In-combat test is `CombatManager.Instance.IsInProgress` (a non-null pcs doesn't mean combat).

- `MegaCrit.Sts2.Core.Combat.CombatManager`: `static Instance`; `IsInProgress`, `IsOverOrEnding`, `IsAboutToLose`, `PlayerActionsDisabled`, `IsPaused`; `bool IsPlayerReadyToEndTurn(Player)`; `bool IsPartOfPlayerTurn(Player)`; `PlayersTakingExtraTurn`; `bool AllPlayersReadyToEndTurn()` (throws outside combat).
  - Events: `CombatSetUp` (IsInProgress still false), `TurnStarted(state)` (check `state.CurrentSide == CombatSide.Player`), `TurnEnded` (every side switch), `PlayerEndedTurn`, `PlayerUnendedTurn`, `CombatWon`, `CombatEnded`; `StateTracker.CombatStateChanged` (coalesced). No `CombatBegan` in v0.107.1.
- `ICombatState`/`CombatState`: `Players`, `Enemies`, `Allies`, `PlayerCreatures`, `HittableEnemies`, `CurrentSide`, `RoundNumber`.
- `MegaCrit.Sts2.Core.Entities.Players.PlayerCombatState`: `Hand`, `DrawPile`, `DiscardPile`, `ExhaustPile`, `PlayPile` (CardPile; `.Cards` is `IReadOnlyList<CardModel>`; events ContentsChanged/CardAdded/CardRemoved); `Energy`, `MaxEnergy` (hook-modified), `Stars`, `OrbQueue` (`.Orbs`, [0] evoked next; `.Capacity`; orb `PassiveVal`/`EvokeVal` include Focus), `Pets`, `Phase` (`PlayerTurnPhase`), `TurnNumber` (restarts at 1 each combat); events `EnergyChanged`, `StarsChanged`, `PlayerTurnPhaseChanged`.
  - `Hand.Cards` is in on-screen left-to-right order. `DrawPile.Cards[0]` is the next draw: hidden from humans, so never expose draw order (send the draw pile sorted). `CardPile.MaxCardsInHand = 10`. `PileType.X.GetPile(player)` also works.
- `MegaCrit.Sts2.Core.Models.CardModel`: `Id.Entry`, `Title`, `Type`, `Rarity`, `TargetType`, `IsUpgraded`, `CurrentUpgradeLevel`, `Keywords`, `ShouldRetainThisTurn`, `IsSlyThisTurn`, `ExhaustOnNextPlay`, `Enchantment`, `DeckVersion`, `EnergyCost` (CardEnergyCost: `CostsX`; `GetWithModifiers(CostModifiers.All)` is the displayed cost, negative = no cost; `GetAmountToSpend()`), `HasStarCostX`, `GetStarCostWithModifiers()`, `Pile` (`?.Type`).
  - `bool CanPlay(out UnplayableReason reason, out AbstractModel? preventer)` (flags enum; test `EnergyCostTooHigh|StarCostTooHigh` bits directly). `bool CanPlayTargeting(Creature?)`; `IsValidTarget(Creature?)`.
  - Live numbers as NCard does: `DynamicVars.ClearPreview()`, `UpdateDynamicVarPreview(mode, target, DynamicVars)`, then `PreviewValue` of each DamageVar/BlockVar/CalculatedDamage. Text: `GetDescriptionForPile(PileType.Hand, target)`. Or without touching the card: `Hook.ModifyDamage(runState, combatState, target, dealer, base, props, card, ModifyDamageHookType.All, CardPreviewMode.Normal, out _)` (10 params) and `Hook.ModifyBlock(cs, me.Creature, base, props, card, null, out _)`.
  - CanPlay ignores phase/turn and still sees queued-but-unplayed cards in hand with energy unspent; subtract our own pending plays.
- `MegaCrit.Sts2.Core.Entities.Creatures.Creature`: `Name`, `CurrentHp`, `MaxHp`, `Block`, `Powers`, `IsAlive`, `IsDead`, `IsHittable`, `IsPrimaryEnemy`, `IsStunned`, `Side`, `Monster` (MonsterModel), `CombatId`, `GetPowerAmount<T>()`.
  - `PowerModel`: `Id.Entry`, `Amount`, `DisplayAmount`, `TypeForCurrentAmount` (buff/debuff), `StackType`, `InstanceType`, `IsVisible`.
- Intents: `MoveState mv = enemy.Monster.NextMove` (`mv.Id == "STUNNED"` when stunned); iterate `mv.Intents`. Test `is AttackIntent a` (DeathBlowIntent is an AttackIntent with IntentType DeathBlow). `targets = cs.Players.Select(p => p.Creature)`; per hit `a.GetSingleDamage(targets, enemy)`, hits `a.Repeats`, total `a.GetTotalDamage(targets, enemy)` (computed against the local player). Label `a.GetIntentLabel(targets, e).GetFormattedText()`. FromMonster attacks hit every player. Also `StatusIntent.CardCount`, `DebuffIntent`, `Monster.IntendsToAttack`. Intents can change mid-turn; re-read before each decision.
- Potions: `PotionModel` has `TargetType` (read at decision time), `Usage` (AnyTime/CombatOnly/Automatic), `IsQueued`, `PassesCustomUsabilityCheck`, `CanThrowAtAlly()`, `IsValidTarget()`.

## c. Actions the way the UI takes them

May-act gate (TryManualPlay, EnqueueManualUse and RequestEnqueue check none of this):
`CombatManager.IsInProgress && !IsOverOrEnding`; `me.Creature.IsAlive`; `pcs.Phase == PlayerTurnPhase.Play`; `RunManager.Instance.ActionQueueSynchronizer.CombatState == ActionSynchronizerCombatState.PlayPhase`; `!PlayerActionsDisabled`; `!IsPlayerReadyToEndTurn(me)`; `IsPartOfPlayerTurn(me)`; `NPlayerHand.Instance.CurrentMode == NPlayerHand.Mode.Play && !InCardPlay && !PeekButton.IsPeeking`; `NOverlayStack.Instance.ScreenCount == 0`. Plus our own latches: no end-turn already requested this turn, no tracked request pending. New turn: wait for `Phase == Play && TurnNumber > lastPlayedTurn`.

- Play a card: `bool CardModel.TryManualPlay(Creature? target)` (checks CanPlayTargeting, then `RequestEnqueue(new PlayCardAction(card, target))`). Don't emit Pressed on hand holders in Play mode (starts a drag).
  - Targets: `AnyEnemy` = a living enemy from `cs.HittableEnemies` passing `card.CanPlayTargeting(t)` and `Hook.ShouldAllowTargeting(cs, t, out _)`. `AnyAlly` = a living PlayerCreature other than me. Every other TargetType (Self, AllEnemies, RandomEnemy, AllAllies, AnyPlayer, Osty, None) takes null.
- Use a potion: `void PotionModel.EnqueueManualUse(Creature? target)` (sets IsQueued, `RequestEnqueue(new UsePotionAction(potion, target, isCombatInProgress))`, no validation). Targets: AnyEnemy = enemy; AnyPlayer = any living player creature when `CanThrowAtAlly()`, else null; Self = null or me.Creature; AllEnemies/TargetedNoCreature = null. Gate: `!IsQueued`, alive, `me.CanRemovePotions`, `PassesCustomUsabilityCheck`, and the may-act gate for CombatOnly potions.
- Discard a potion: `RequestEnqueue(new DiscardPotionGameAction(Player player, uint potionSlotIndex, bool isCombatInProgress))`.
- End turn: `RequestEnqueue(new EndPlayerTurnAction(Player player, int turnNumber))` with `pcs.TurnNumber`. Don't ForceClick the button. Latch it ourselves (PlayerActionsDisabled flips only when the action executes). Undo (MP only): `new UndoEndPlayerTurnAction(Player, int turnNumber)`. Never send `ReadyToBeginEnemyTurnAction`.
- Tracking a request: `GameAction.Cancel()` never completes `CompletionTask`. Subscribe `RunManager.Instance.ActionQueueSet.ActionEnqueued` once per run; match `action.OwnerId == LocalContext.NetId` plus type (PlayCardAction: `NetCombatCard`, `TargetId`; UsePotionAction: `PotionIndex`). Attach `BeforeCancelled` (rejected), `AfterFinished` (done), `BeforePausedForPlayerChoice`; first wins (TrySetResult), BeforeCancelled decides. Singleplayer/host: the event fires synchronously inside RequestEnqueue, so subscribe before calling. Client: fires later with a new object from the host echo. Fallbacks: timeout, `card.Pile?.Type != PileType.Hand`, potion slot becomes null.
- Idle: no pending tracked request && `!ActionExecutor.IsRunning` && `ActionQueueSet.IsEmpty` && `NMapScreen.Instance?.IsTraveling != true` && `!NetService.IsGameLoading`. IsEmpty stays false while a choice is open and can stick false after an enqueue-time cancel; always use timeouts.
- Mid-action choices (CardSelectCmd pauses the action; UI only on the chooser's machine):
  - Hand select: `NPlayerHand.Instance.IsInCardSelection` (Mode.SimpleSelect or UpgradeSelect). Per pick: `holder = hand.ActiveHolders.First(h => h.CardModel == c); holder.EmitSignal(NCardHolder.SignalName.Pressed, holder)`; re-query each time. Then ForceClick `hand.GetNode<NConfirmButton>("%SelectModeConfirmButton")` once IsEnabled.
  - Overlay select: `NOverlayStack.Instance.Peek()` is `NSimpleCardSelectScreen` / `NCombatPileCardSelectScreen` / `NChooseACardSelectionScreen` (all ICardSelector); see e.
  - Prompt and Min/Max: read-only Harmony prefix on static `CardSelectCmd.FromHand`, `FromHandForUpgrade`, `FromSimpleGrid`, `FromSimpleGridForRewards`, `FromCombatPile`, `FromChooseACardScreen`, recording args when `LocalContext.IsMe(player)`.

## d. Map

- `rs.Map` (ActMap; NullActMap until generated). MapPoints keyed by `MapCoord(col,row)`: `.coord`, `.PointType` (MapPointType), `.Children`, parents, `Quests`. `GetAllMapPoints()` covers rows 1..GetRowCount()-1. `StartingMapPoint` row 0, `BossMapPoint` row GetRowCount(), `SecondBossMapPoint` row +1 (may be null). Compare by coord (no Equals override; map rebuilt on act change and Golden Compass).
- Location: `rs.VisitedMapCoords[^1]` (empty at act start, except with Neow in act 1).
- Next nodes (mirrors private `NMapScreen.RecalculateTravelability`): nothing visited → {Start}; on first boss with a second boss → {SecondBoss}; on last grid row → {Boss}; else `MapTravel.GetTravelablePointsFrom(rs, map.GetPoint(last))`.
- Choose: wait for `NMapScreen.Instance.IsOpen && IsTravelEnabled && !IsTraveling`, point `IsEnabled`, and `!CombatManager.IsInProgress`. Find the `NMapPoint p` under NMapScreen.Instance with `p.Point.coord == target`, call `p.ForceClick()` (→ `OnMapPointSelectedLocally` → VoteForMapCoordAction). Co-op: host picks once all voted. Arrival = `rs.CurrentMapCoord == target && rs.CurrentRoom != null && !NMapScreen.Instance.IsTraveling`.
- Planning: point types are fixed at generation; only Unknown rolls on entry (`rs.Odds.UnknownMapPoint`). Bosses and the Ancient are on `rs.Act` (`BossEncounter`, `SecondBossEncounter`, `Ancient`).
- Next act: after the boss, ForceClick NRewardsScreen's `NProceedButton` once (→ `ActChangeSynchronizer.SetLocalPlayerReady()`). No stale guard: latch "voted for act N" ourselves. Victory goes through TheArchitect's PROCEED option.

## e. Rewards, card choices, treasure, shop, rest, events

Every reward and selection screen is an IOverlayScreen on `NOverlayStack.Instance`. Dispatch on the concrete type of `Peek()` with `is`. Check `NMapScreen.Instance.IsOpen` first: terminal reward screens stay on the stack under the map until the room changes.

- `NRewardsScreen`: all `NRewardButton` under it; `b.Reward` is `GoldReward` (.Amount), `PotionReward` (.Potion), `RelicReward` (.Relic), `CardReward` (.Cards, .CanSkip, .CanReroll), `SpecialCardReward`, `CardRemovalReward`. Claim with `b.ForceClick()` only when `b.IsEnabled` and only on the topmost rewards screen. A potion with full slots re-enables its button: track attempts. Proceed: `screen.GetNode<NProceedButton>("ProceedButton")`; `IsSkip` says whether it reads Skip.
- Card reward `NCardRewardSelectionScreen`: options = `NGridCardHolder` children of `"UI/CardRow"`; emit Pressed once. Alternatives = `NCardRewardAlternativeButton` children of `"UI/RewardAlternatives"` (Skip, then Reroll, then Sacrifice), ForceClick. Re-read holders after a reroll.
- Deck screens: `grid = screen.GetNode<NCardGrid>("%CardGrid")`; `grid.GetCardHolder(card)` then Pressed or `grid.EmitSignal(NCardGrid.SignalName.HolderPressed, holder)`. Grid is virtualized: for an off-screen card invoke the screen's protected `OnCardClicked(CardModel)` via reflection.
  - `NDeckCardSelectScreen` (removal/generic): pick, preview opens, ForceClick `"%PreviewConfirm"`. `"%Close"` cancels.
  - `NDeckUpgradeSelectScreen`: Max 1: press one card, then `Confirm` inside `"%UpgradeSinglePreviewContainer"`.
  - `NDeckTransformSelectScreen`: `"%PreviewContainer"` then its `Confirm`.
  - `NDeckEnchantSelectScreen`: `"%EnchantSinglePreviewContainer"` / `"%EnchantMultiPreviewContainer"` then `Confirm`.
  - `NSimpleCardSelectScreen` / `NCombatPileCardSelectScreen`: complete themselves at MaxSelect unless `RequireManualConfirmation`; then `"%Confirm"` when IsEnabled.
  - `NChooseACardSelectionScreen`: wait > 350 ms after open; Pressed once on an `NGridCardHolder` in `"CardRow"`; `"SkipButton"` only if canSkip.
  - `NChooseABundleSelectionScreen`: ForceClick `bundle.Hitbox`, then `"%Confirm"`.
  - `NCrystalSphereScreen`: local minigame; click hidden cells, then a rewards screen follows.
  - Static factories (`NRewardsScreen.ShowScreen`, `NCardRewardSelectionScreen.ShowScreen/RefreshOptions`, `NDeck*SelectScreen.ShowScreen/Create`, `NChooseACardSelectionScreen.ShowScreen`) can be postfixed to capture options and prefs.
- Treasure (not an overlay; `NRun.Instance.TreasureRoom`): ForceClick the `"Chest"` node once; handle any rewards screen first; click an enabled `NTreasureRoomRelicHolder` once (→ `TreasureRoomRelicSynchronizer.PickRelicLocally(index)`). PickRelicLocally throws if voting isn't active; holders stay enabled during the award animation. Await `RelicPickingFinished()` before `ProceedButton`; leaving early loses the relic.
- Shop (no action queue): `inv = NMerchantRoom.Instance.Inventory.Inventory`. `CharacterCardEntries` (IsOnSale), `ColorlessCardEntries`, `RelicEntries`, `PotionEntries`, `CardRemovalEntry`, each with `IsStocked`, `Cost`, `EnoughGold`; item is `CreationResult.Card` for cards, `Model` for relics/potions. Open with `room.OpenInventory()`. Buy: `entry.OnTryPurchaseWrapper(MerchantInventory? inventory, bool ignoreCost = false)` → `Task<bool>`; don't block on it (Orrery/Cauldron push a rewards overlay first). Removal: keep the entry typed `MerchantCardRemovalEntry` (extra `bool cancelable = true`), then the NDeckCardSelectScreen flow. Leave: `"%BackButton"` if inventory open, then `room.ProceedButton`. The merchant FTUE eats the first click.
- Rest: `NRestSiteRoom.Instance.Options` (`OptionId`, `Title`, `Description`, `IsEnabled`); `GetButtonForOption(opt).ForceClick()` once (→ `RestSiteSynchronizer.ChooseLocalOption(index)`). Smith opens NDeckUpgradeSelectScreen, Cook opens NDeckCardSelectScreen. Mend (co-op) needs NTargetManager targeting. Proceed once `ProceedButton.IsEnabled`.
- Events: `ev = RunManager.Instance.EventSynchronizer.GetLocalEvent()`; `ev.CurrentOptions` (`Title`, `Description`, `IsLocked`, `IsProceed`, `TextKey`, `WillKillPlayer`), `ev.IsFinished`, `ev.IsShared`, `StateChanged`. Choose by ForceClicking the `NEventOptionButton` in `NEventRoom.Instance.Layout.OptionButtons` (`!IsLocked && IsEnabled`) (→ `EventSynchronizer.ChooseLocalOption(index)`). Shared events are a vote. Leave only via the option with `IsProceed && TextKey == "PROCEED"` when `ev.IsFinished`. Trial's `DOUBLE_DOWN` is IsProceed but opens the abandon popup. Ancients (`NAncientEventLayout`): dialogue done when `layout.DefaultFocusedControl != null`. Event combats: `CurrentRoomCount > 1` with BaseRoom an EventRoom; re-fetch `NRun.Instance.EventRoom` afterwards.

## f. Which screen is up, and is it waiting for me

0. Ready when `NGame.Instance?.MainMenu != null || CurrentRunNode != null`.
1. Busy if: `NGame.Instance.Transition.InTransition`; `RunManager.IsCleaningUp`; `IsInProgress && NetService.IsGameLoading`; a TimeoutOverlay is shown; `NMapScreen.Instance?.IsTraveling`; or `IsInProgress && NRun.Instance?.GlobalUi == null`.
2. `ctx = ActiveScreenContext.Instance.GetCurrentScreen()` (`MegaCrit.Sts2.Core.Nodes.Screens.ScreenContext`; `IScreenContext?`) in try/catch. Layer order: feedback, modal (`NModalContainer.Instance.OpenModal`), inspect screens, logo, main menu and submenus, then in a run: capstone (deck view or pause; `ICapstoneScreen`), `NMapScreen` if IsOpen, `NOverlayStack.Peek()`, then the room node (event, combat, treasure, rest site, map room, merchant or its inventory).
3. Switch on type. Modals: click FTUE confirm buttons; leave error popups and `NConfirmModLoadingPopup` (Yes quits) to the human. `NCombatRoom` counts only when `Mode == ActiveCombat`. Logical room: `rs.CurrentRoom.RoomType` (Unassigned/Monster/Elite/Boss/Treasure/Shop/Event/RestSite/Map); wait while null or Unassigned. Game over is `NGameOverScreen` on the overlay stack; a win when `CurrentRoom.IsVictoryRoom`.
- Push signal: `ActiveScreenContext.Instance.Updated` (not fired for reward completion, button enable changes or turns), so keep a polling fallback.
- AutoSlay's loop: dispatch on RoomType, wait for rewards or map, drain NOverlayStack by Peek() type with a 3-strikes no-progress check, handle act change, then the map. Polls every 100 ms with a 30 s watchdog.

## g. Local multiplayer on one Mac

- `MegaCrit.Sts2.Core.Helpers.CommandLineHelper` (static): `HasArg`, `TryGetValue`, `GetValue`. Reads Godot `OS.GetCmdlineArgs()` once; args after a bare `--` are not seen. `--key=value` or `--key value`; case-sensitive. Use `=` for custom valueless flags (`--sts2bot=1`).
- `fastmp` switches every host/load/join to ENet: UDP 0.0.0.0:33771, 4 players, host NetId 1; skips logo and MP warning. Values: `host_standard`/`host_daily`/`host_custom` (host now), `host` (open MP menu in ENet mode), `load` (re-host saved MP run), `join` (one attempt at 127.0.0.1:33771).
- `clientId`: ENet NetId for the auto-join (default 1000) and the no-Steam save folder `~/Library/Application Support/SlayTheSpire2/default/<id>/`. Never 1 for a client, never reuse, keep 1000.
- `--force-steam off` skips Steam. Steam P2P and ENet don't mix: Mark hosts over ENet with Steam on via launch option `--fastmp host_standard` (or `--fastmp host` to Load/Custom).
- Bot instance: `"…/SlayTheSpire2.app/Contents/MacOS/Slay the Spire 2" --force-steam off --clientId 1000 --fastmp join --sts2bot=1 --log-file "$HOME/sts2bot/godot.log"`, started after the host is in character select (run the binary directly or `open -n … --args`).
- A fresh default/1000 profile shows the mod-consent popup (Yes saves and quits) and the EA disclaimer: pre-seed by copying Mark's `steam/<id>/settings.save` (mods_enabled, seen_ea_disclaimer true) with fullscreen false, window_size 1280x720, schema_version 5.
- Join check: version string, then the exact id-version list of `affects_gameplay` mods, then the ModelId hash. Mark's Workshop BetterSpire2 is affects_gameplay=true and the no-Steam bot never loads Workshop mods: put the bot mod and a copy of BetterSpire2 in `Contents/MacOS/mods/` (local copies win over Workshop).
- In mod code: role from `CommandLineHelper.GetValue("fastmp")`, `SteamInitializer.Initialized`, `PlatformUtil.GetLocalPlayerId(PlatformType.None)`; NetId from `RunManager.Instance.NetService.NetId` in a run or `NCharacterSelectScreen.Lobby.NetService.NetId` in the lobby. Retry join: `NGame.Instance.MainMenu.OpenMultiplayerSubmenu().OnJoinFriendsPressed()`; on NErrorPopup: `NModalContainer.Instance.Clear()`, `MainMenu.SubmenuStack.Pop()`, retry.
- Crash recovery: a killed bot stays a ghost (IdCollision on rejoin); host must back out and re-host. Clients can't rejoin a running run. Resume an ENet co-op save with `--fastmp host` + Load. Never `--fastmp load` or Load without fastmp (renames the save to .corrupt).

## h. Mod loading and manifest

- Scanned once at startup: `<exe dir>/mods` (= `SlayTheSpire2.app/Contents/MacOS/mods/`), `<exe dir>/mods_STEAMTEST` (don't use), Workshop items when Steam is up. Every *.json is tried as a manifest.
- Manifest: `id`, `name`, `author`, `description`, `version`, `has_pck`, `has_dll`, `dependencies`, `affects_gameplay` (defaults true), `min_game_version` (omit or ≤ 0.107.1). DLL is `<id>.dll` beside it.
- Entry: `[ModInitializer("Init")]` on a class with a static parameterless method; called on the main thread before ModelDb.Init and the main menu. With the attribute, PatchAll is not run; create our own Harmony instance.
- Mods load only after consent (`settings.save mod_settings.mods_enabled = true`). Any loaded mod switches saves to `steam/<id>/modded/profileN`.
- Co-op safety for our DLL: `affects_gameplay: false`, declare no AbstractModel subclasses, no INetMessage or INetAction types. Observe through C# events and Harmony patches only.
- Dev console (backtick) works; debug commands unlock when modded.

## v0.107.1 vs beta differences

Missing in v0.107.1: `CombatManager.CombatBegan`, `CurrentCombatId`, `IsCurrentLiveCombat`; `NGame.GameStartupComplete`, `GetGameVersion` (use `ReleaseInfoManager.Instance.ReleaseInfo?.Version`); `PeerVersionInfo`, `HandshakeManager`; `CardSelectCmd.LocalSelector`; `BranchingPlayerChoiceContext`; `RunLobby.Players/PlayerIds`; public `RunManager.WinRun`, `FadeIn`, `FadeOut`. Renamed: `Player.CanUseOrRemovePotions` → `CanRemovePotions`; seeds are uint; `Hook.ModifyDamage` has no CardPlay param; `NetHostGameService()`/`JoinFlow()` take no args. Behaviour: `Cancel()` never completes CompletionTask; `MoveToMapCoordAction` returns before travel ends; `VoteForMapCoordAction` is NonCombat; act-change vote has no stale guard; `PickRelicLocally` throws outside voting.
